# `local/` — 本機文件（不進版控）

這個目錄裡的檔案**不會進版控**（`.gitignore` 規則是 `local/*` 加上一個例外：這份
README）。**這個 repo 是公開的**，所以任何不該被公開的文字都放這裡，不要放進 `docs/`。

## 適合放什麼

人寫的、只屬於這台機器或這個部署的文件：

- `handover.md` —— 跨 session 的工作交接筆記（原本在 repo 根目錄，2026-09-12 搬進來）。
- 業務／售前的內部指引、話術、報價相關的草稿。
- 特定客戶的環境筆記、硬體與網路拓撲、聯絡窗口。
- 任何含客戶名稱、內部代號或商務條件的草稿。

## 不要放什麼

**執行期的設定與狀態不要搬進來**，它們的位置是程式與 Docker 寫死的，各自已有
`.gitignore` 規則：

| 路徑 | 為什麼不能移動 |
|---|---|
| `.env` | Docker Compose 從 repo 根目錄讀取 |
| `config.toml` | `app/config.py` 從 repo 根目錄讀取 |
| `data/` | SQLite、上傳檔、Chroma 索引；`NOTEBOOKLM_DATA_DIR` 預設值 |
| `logs/` | 輪替日誌 |

也不要放需要被 review 或被別人依賴的工程文件——那些屬於 `docs/`，要進版控。

## 三個要知道的風險

1. **沒有備份。** 這裡的檔案不在版控裡，不會同步到你其他台電腦，任何要共用或要留存的
   正本請放公司的雲端硬碟，這裡只當本機工作副本。
2. **`git clean -xdf` 會直接刪掉這裡的所有檔案**（README 除外，它有進版控），而且不會提示。
3. **每個 git worktree 各有一份。** 在 worktree 裡建立的檔案，會隨著該 worktree 被移除而
   消失。要留下來的東西請放在主 checkout 的 `local/`。
